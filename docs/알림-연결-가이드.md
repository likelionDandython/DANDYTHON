# 알림 화면 연결 가이드 (1단계: 알림 목록 · 벨 · 설정)

BE 답변(11/4)의 알림 API에 맞춰 만든 화면이에요. 기존 화면 파일은 수정하지 않았어요. 아래 두 곳만 팀원이 붙여 주세요.

## 이미 연결된 것
- 라우트 2개: `/guardian/notifications`(알림 목록), `/guardian/notifications/settings`(알림 설정)
  - `design/routes.tsx` 에 넣어 뒀고, `routes.tsx` 가 `...designRoutes.guardian` 으로 이미 펼쳐 쓰고 있어서 따로 할 일이 없어요.

## 붙여야 하는 곳 2군데 (기존 파일이라 직접 수정 안 했어요)
1. **요청자 홈 상단**: `screens/guardian/Main.tsx` 의 `GuardianHome` 제목줄 오른쪽에
   ```tsx
   import { BellButton } from '../../components/common/BellButton'
   ...
   <BellButton />
   ```
   안 읽은 알림이 있으면 빨간 점이 떠요.
2. **MY**: `GuardianMy` 에 알림 설정으로 가는 줄을 하나 넣어요.
   ```tsx
   <Link to="/guardian/notifications/settings">알림 설정</Link>
   ```

## 쓰는 서버 API (BE 답변 기준)
| 화면 | API |
|---|---|
| 알림 목록 | `GET /api/notifications` → `{ unreadCount, notifications[] }` |
| 하나 읽음 | `PATCH /api/notifications/{id}/read` |
| 모두 읽음 | `PATCH /api/notifications/read-all` |
| 설정 불러오기·저장 | `GET` · `PUT /api/notifications/settings` (5개 스위치) |

API 코드는 `design/notificationsApi.ts` 에 따로 뒀어요 (`api/services.ts` 는 그대로).

## 알림을 누르면
알림에는 `visitId` 만 있어서, `GET /visits/{visitId}` 로 `requestId` 를 찾아 `/guardian/live?requestId=` (동행 현황)로 이동해요.

## 아직 안 한 것 (2단계: 휴대폰 푸시)
- Firebase SDK, 서비스 워커(`firebase-messaging-sw.js`), `manifest.json`, 푸시 토큰 등록(`POST /notifications/push-token`)
- BE 가 Firebase 웹 config 와 VAPID 키를 줘야 시작할 수 있어요. HTTPS 배포도 필요해요(localhost 는 예외).
- 아이폰은 홈 화면에 추가한 경우에만 푸시가 와요(iOS 16.4 이상). 시연은 안드로이드나 PC 크롬을 권해요.

## BE 확인이 필요한 것
- 알림 `type` 값 전체 목록: 지금 확정된 건 `ARRIVAL` 뿐이에요. 나머지(`DEPARTURE` `TREATMENT_DONE` `HOMECOMING` `WAITING`)는 추측이라, 틀리면 '소식'으로 보여요.
- 알림 문구에 "어르신"이 들어가는 예시가 있어요. 호칭을 "동행받는 분(님)"으로 맞춰 달라고 부탁해야 해요.
- 알림 API 배포 일정 (11/4 17:03 기준 배포본에는 없어요).

## 확인 상태
타입 검사만 했고 화면 실행으로는 확인하지 못했어요. 서버에 알림 API가 아직 없으면 목록·설정은 오류 안내가 떠요.
